# Raster support

Raster 2.x is the actively maintained line. SwiftPM is the supported package manager, and platform support is documented in the [framework documentation](docs/content/docs/reference/platform-support.mdx).

MetalPetal 1.26.x remains available as the frozen compatibility line under its original package and module name. Only a severe security or data-corruption defect can justify another 1.26.x release; ordinary fixes and new development belong to Raster.
