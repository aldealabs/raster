# MetalPetal 1.x support

MetalPetal 1.x is frozen in maintenance mode. SwiftPM is the sole supported package manager from 1.26.0 onward, and the source deployment floors remain macOS 10.13, iOS 11, and tvOS 13.

The 1.26.0 candidate was validated on Xcode 26.3. No new MetalPetal features are planned after 1.26.0; only a severe security or data-corruption defect can justify a 1.26.x update.
