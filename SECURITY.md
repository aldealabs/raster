# Security policy

Report suspected vulnerabilities privately to `security@aldealabs.com`. Include a minimal reproduction, affected versions and platforms, the expected and observed behavior, and your assessment of the security impact.

We target an acknowledgement within seven calendar days. This is an acknowledgement target, not a remediation deadline, and no remediation timeline is guaranteed.

If you do not receive an acknowledgement within seven calendar days, use a published Aldea contact channel to request a private security contact without disclosing vulnerability details publicly.
